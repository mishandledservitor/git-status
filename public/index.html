git status

Tokens are separated by spaces and all of them must match.

word
matches the repo name, checked-out branch or path
-word
excludes a match
folder:x
the subfolder under the scanned root, e.g. folder:mishandled
branch:x
the checked-out branch, e.g. branch:prod
is:state
attention, dirty, clean, ahead, behind, diverged, detached, stash, noremote, error

Folders to scan

One path per line. ~ is expanded.

Repos to show

Unticked repos are skipped entirely. New clones appear automatically. Tick a folder to select everything in it.
